## 🚀 Installation

Since this extension is open-source, you can install it directly via Chrome Developer Mode:

1. Clone or download this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the top right corner.
4. Click **Load unpacked**.
5. Select the folder containing the extension files.

## 🔑 Setup (Get your Free Ahrefs API Key)

This **da checker** runs on the official [Ahrefs Free Domain Rating API](https://docs.ahrefs.com/en/api/reference/public/get-domain-rating-free).

1. [Sign up](https://ahrefs.com/) for a free Ahrefs account.
2. Navigate to your [Ahrefs Account Settings \u2192 API keys](https://app.ahrefs.com/account/api-keys).
3. Generate a new **APIv3 Key**. (It's 100% free to query the DR endpoint).
4. Right-click the **DA DR Checker** extension icon in your Chrome toolbar and select **Options**.
5. Paste your API key, hit save, and you're ready to check domain authority!
